# RLTP JSON-LD Contexts

The pinned JSON-LD contexts. Implementations MUST use the pinned documents, never a live fetch.

- [`rltp-v1.jsonld`](rltp-v1.jsonld) — the RLTP vocabulary, `https://real-life.org/rltp/v1`, pinned by value.
- [`dtg-v1.jsonld`](dtg-v1.jsonld) — a byte-exact copy of the DTG credential context `https://registry.trustoverip.org/dtg/context/v1` (DTG Credentials WD 0.6.0, Context Versions), SHA-256 `3e1376acf401016a0162c1cdb31e44a85a7dd56749caed94a1dc0a0be6cbb448`. The encounter credential `rltp-encounter-credential/0.26` lists it second (Encounter 2.3).

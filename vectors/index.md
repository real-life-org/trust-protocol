# RLTP Test Vectors

Deterministic test vectors (seal, identity derivation, encounter cards, DTG credentials, visibility). Implementations MUST reproduce them byte-for-byte; negatives must fail at their declared stage.

- [`access-conflicts.json`](access-conflicts.json) — authority DAGs under the Access 0.54 conflict matrix (§3.5, §3.6): per case the operations `{ label, id, kind, author, subject, role, preds }`, the expected member set, merged epoch and status per operation (`canonical`, `removed-disposed`, `invalid`); the field meanings are in the file's `format` member. No schema: like `member-mapping.json`, the file documents itself. Generated by `scripts/gen-access-conflicts-vector.mjs`, re-derived by `conformance/runner.mjs`.
